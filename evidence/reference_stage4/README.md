# Bằng chứng tham khảo

Kết quả thực chạy trên Python 3.12/Linux trong môi trường tạo gói: 10 lượt, 18 ca/lượt. Đây không phải kết quả chạy trên máy Windows của nhóm. Chạy scripts.run_experiments để tạo bằng chứng của bạn. Timestamp UTC trong metadata; latency phụ thuộc máy và dùng TestClient, không đo mạng thật.
